# Director Breakdown

## When to use
Translate scene meaning into audience information, performance intention, blocking, coverage priorities and pickup protection.

## Procedure
1. Read the locked scene without designing shots first. State what the audience should understand, anticipate and feel at entry/turn/exit.
2. For each character define moment-to-moment objective, tactic, pressure, playable behavior and the reaction moments that must be seen.
3. Map blocking around dramatic leverage and geography; use movement when it changes relationship, information or power rather than to make frames busy.
4. Define visual-information order: what is revealed, withheld, foregrounded or discovered and whose point of view controls it.
5. Specify coverage intent and pickup protection based on edit needs, performance variability and generative/animation risk.
6. Only then hand dramatic constraints to cinematography/storyboard/ShotSpec; camera choices must cite the scene intention they serve.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
