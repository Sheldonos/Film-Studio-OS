# Source Adaptation

## When to use
Convert a licensed book, treatment, article, memoir or source package into a traceable adaptation mandate and change ledger.

## Procedure
1. Load the exact source passages, canon extraction, approved adaptation mandate, rights constraints, target format/runtime and frozen author/studio invariants.
2. Build a source map that distinguishes story fact/canon, narrative voice, optional texture, legally restricted material and unresolved contradictions.
3. State an adaptation thesis: what experience/argument must survive the medium change and what the screen version can legitimately transform.
4. For each material source unit record one decision: keep, compress, merge, reorder, remove or add; cite the source unit and explain narrative, runtime and production consequences.
5. Map source units to feature sequences, limited-series episodes or episodic engines; track displaced setups/payoffs and character/world consequences before drafting scenes.
6. Run a regression pass from proposed outline back to source and mandate. Escalate fidelity conflicts instead of solving them by silent invention.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
