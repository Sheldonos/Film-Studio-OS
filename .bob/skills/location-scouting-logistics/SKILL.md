# Location Scouting & Logistics

## When to use
Translate story needs into creative, technical, access, permit, logistics and safety location evaluation packages.

## Procedure
1. Convert each scene cluster into a scout brief covering dramatic function, geography, period, scale, sightlines, sun/time, acoustics, access, unit footprint, build/dress needs and virtual or generative alternatives.
2. Research candidate locations only from authorized sources and label remote observations as unverified; capture exact address or virtual-asset identity, contact path, reference provenance and recency.
3. Evaluate creative fit alongside permits, ownership, neighbors, parking, base camp, power, data, restrooms, accessibility, load-in, weather, tides, aviation, wildlife, restoration and community impact.
4. Run technical checks for camera positions, lens distances, sound noise, RF, lighting control, sun path, power, rigging, scans/plates/HDRI and emergency access; route hazards to qualified specialists.
5. Build a comparable matrix with hard blockers, mitigations, schedule/cost assumptions, company-move impact, backup location and required in-person tech scout evidence.
6. Record human selections, permits, agreements and restrictions as separate evidence; issue location packets and day-of contacts only after authorized owners validate them.

## Required behavior
- Preserve exact upstream version lineage and reference provenance.
- Separate verified evidence, inference, assumptions and unknowns.
- Require independent review for consequential artifacts.
- Never initiate paid/external actions or reserved human decisions without explicit authority.
