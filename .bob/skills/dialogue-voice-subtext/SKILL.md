# Dialogue Voice Subtext

## When to use
Write or audit differentiated dialogue, subtext, exposition concealment, pauses, interruptions and actor speakability.

## Procedure
1. Load every speaker’s VoiceFingerprint, current objective/tactic, relationship/status state, knowledge state and what the image/action already communicates.
2. For each candidate line separate literal wording, hidden intention, desired listener effect, status move and new information. Delete lines whose only function duplicates visible action.
3. Vary diction, syntax, sentence length, rhythm, directness/evasion and metaphor domain according to the speaker—not a global “witty” style.
4. Bury exposition inside tactical behavior: bargaining, accusation, correction, concealment, seduction, deflection, instruction under pressure or misinterpretation.
5. Score interruption, overlap, silence, breath length and reaction space at performance speed; reserve pauses for thought/status/emotion rather than generic dramatic punctuation.
6. Build callbacks and banter from relationship history, asymmetry of knowledge and present stakes. Each volley must change pressure, information or affection/status.
7. Run names-removed voice identification, on-the-nose detection, AI-generic phrasing detection and speakability/table-read checks before handoff.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
