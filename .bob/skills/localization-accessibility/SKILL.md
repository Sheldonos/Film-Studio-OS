# Localization Accessibility

## When to use
Prepare translation, dubbing/subtitle/accessibility requirements while respecting voice consent, culture and territory constraints.

## Procedure
1. Load locked dialogue/narration, timing, terminology/character voice guide, territory requirements, performer/voice consent and delivery spec.
2. Create translation brief preserving meaning, subtext, character register, humor/idiom and cultural context; flag material requiring adaptation rather than literal translation.
3. For subtitles, time to actual speech/readability and preserve speaker/SDH/accessibility conventions required by destination.
4. For dubbing, bind authorized voice/casting strategy and consent scope; adapt line length/rhythm without changing locked story information.
5. Run cultural review, back-check critical plot/legal/documentary claims and verify graphics/on-screen text/credits/territory edits.
6. Version each locale independently so a source-language revision marks only affected downstream locale assets stale.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
