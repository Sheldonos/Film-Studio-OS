# Continuity Qc

## When to use
Independently fail or flag shot/sequence continuity contradictions across identity, props, wardrobe, geography, light/time and action.

## Procedure
1. Load intended edit neighbors, authoritative state ledger and ShotSpec continuity constraints for the candidate take.
2. Compare identity, wardrobe/injury/wetness, prop ownership/hand, position, screen direction/eyeline, geography, light/time, action phase and emotional/knowledge state.
3. Check match-on-action and entrance/exit vectors at actual edit frames, not only representative stills.
4. Separate intentional discontinuity with recorded director approval from accidental drift.
5. Classify severity by whether edit/story comprehension can survive; recommend trim, alternate take, repair, insert/cutaway or regeneration.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
