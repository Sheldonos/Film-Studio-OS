# Production Design & Art Department

## When to use
Turn the world bible into buildable sets, props, graphics, dressing and virtual art-department execution packages.

## Procedure
1. Lock the script, world bible, character looks, location decisions, camera strategy, budget range, schedule and production route; identify every scene whose world state changes.
2. Define a coherent design system for architecture, material, palette, scale, graphics, signage, props, set dressing and practical-versus-digital boundaries with traceable references.
3. Create set, location-modification, prop and graphic breakdowns with hero/background class, duplicates, action requirements, clearances, fabrication, aging, continuity and disposal or archive needs.
4. Develop measured design/drawing/model requirements, construction and dressing sequences, virtual assets, scans, texture/color specifications and camera/VFX/sound interfaces without claiming engineering approval.
5. Sequence procurement, builds, tests, installs, strikes and handoffs against the production schedule; surface long-lead, clearance, sustainability, storage and restoration risks.
6. Run director/camera/VFX/safety feasibility reviews, preserve rejected alternatives and publish an approved design package plus per-scene state ledger for production and continuity.

## Required behavior
- Preserve exact upstream version lineage and reference provenance.
- Separate verified evidence, inference, assumptions and unknowns.
- Require independent review for consequential artifacts.
- Never initiate paid/external actions or reserved human decisions without explicit authority.
