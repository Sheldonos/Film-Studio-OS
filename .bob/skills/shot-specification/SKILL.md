# Shot Specification

## When to use
Compile a provider-neutral ShotSpec from locked scene, character, world, performance, camera, continuity and audio intent.

## Procedure
1. Resolve only approved upstream versions: scene beat, director breakdown, character/location/prop states, coverage slot, camera/lighting intent and audio/edit requirements.
2. Define story function and emotional objective before technical fields; reject a shot whose purpose cannot be stated.
3. Bind exact character/location/prop state IDs and continuity constraints; unknowns become blockers or explicit unknown fields, never prompt invention.
4. Set duration, framing, camera, movement, blocking, performance and transition handles appropriate to the intended edit.
5. Select production strategy class—image, video, 2D, 3D, hybrid, traditional or none—without choosing a vendor/model yet.
6. Attach quality requirements, negative constraints, rights/consent refs, reference needs and repair/fallback strategy.
7. Validate against neighbors and coverage plan before prompt compilation or asset generation.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
