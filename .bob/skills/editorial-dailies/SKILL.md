# Editorial Dailies

## When to use
Compare takes, test edit compatibility, build assemblies, diagnose pacing and identify pickups without hiding continuity defects.

## Procedure
1. Ingest all candidate takes with exact ShotSpec/take/QC/provenance and normalize technical playback metadata before creative comparison.
2. Evaluate first for usable performance/story information and continuity, then composition/motion/artifacts; do not select a technically clean take that misses the dramatic beat.
3. Compare takes in sequence context with handles, eyelines, screen direction, action match and dialogue/reaction timing.
4. Mark select, alt, repair, reject and pickup-needed with explicit reason; rejected takes remain searchable learning evidence.
5. Assemble rough sequence timing and flag where no available take satisfies story/edit needs; create pickup requirements rather than hiding gaps with overlong shots.
6. After upstream changes, identify stale edits/takes and reconform only affected regions.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
