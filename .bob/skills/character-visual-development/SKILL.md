# Character Visual Development

## When to use
Build production-grade character reference packages spanning identity, turnaround, expression, silhouette, scale and approved look continuity.

## Procedure
1. Bind the character to the approved script and character bible, separating immutable identity traits, story-period facts, performance cues, optional exploration and prohibited references.
2. Define an identity sheet with silhouette, proportions, facial landmarks, skin/hair detail, posture, movement signature, age or time states and distinguishing features using respectful, non-stereotyped language.
3. Specify a neutral turnaround set—front, profile, three-quarter and back—plus consistent lens, light, scale, color reference and expression/pose matrices so downstream comparisons are meaningful.
4. Layer wardrobe, hair, makeup, injuries, aging, weathering, props and emotional states as versioned variants rather than allowing them to drift into the base identity.
5. Create reference hierarchy and prompt/asset bindings with provenance, rights status, negative constraints and acceptance tolerances for face, silhouette, palette, proportions and state continuity.
6. Run independent multi-view and downstream-shot tests, log mismatches by cause, approve only the reference version that passes defined tolerances and preserve rejected variants.

## Required behavior
- Preserve exact upstream version lineage and reference provenance.
- Separate verified evidence, inference, assumptions and unknowns.
- Require independent review for consequential artifacts.
- Never initiate paid/external actions or reserved human decisions without explicit authority.
