# Master Quality Gate

## When to use
Run independent master QC with hard blockers for rights, approvals, corrupt assets, continuity contradictions and missing evidence.

## Procedure
1. Freeze candidate master/version and verify exact picture/sound/color/subtitle/credit deliverables plus required rights, consent and human release approvals.
2. Run structural validation first: artifact hashes, references, versions, missing media, required provenance and reproduction manifest completeness.
3. Run deterministic technical QC for every metric the installed toolchain can actually measure; unavailable required metrics are blockers, not assumed values.
4. Aggregate automated perceptual/continuity findings without allowing weighted averages to hide critical identity, continuity, security or rights failures.
5. Require independent creative review of story/performance/edit/audio/finish and compare to destination quality bar.
6. Separate blocker failures, preference findings and documented waivers. Only an authorized human can accept waivable consequential risk and release the master.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
