# Coverage Storyboard Previs

## When to use
Design coverage, storyboard/animatic timing and generation-risk previs before expensive shot production.

## Procedure
1. Start from DirectorBreakdown, blocking and camera grammar; enumerate moments the edit must possess: establishing geography, action information, performance beats, reactions, transitions and safety.
2. Build coverage alternatives rather than a single fragile shot plan; identify must-have, preferred and optional shots by narrative/edit value.
3. Storyboard key compositions with character/location/state IDs and clear screen direction; panels represent intent, not decorative concept art.
4. Create animatic timing from dialogue/action/performance cadence and planned transition handles; reserve reaction and edit handles explicitly.
5. Run feasibility against generation/animation limitations: multi-person contact, fast articulated motion, crowd complexity, reflections and continuity-sensitive interactions.
6. For high-risk beats, design alternate coverage or compositing strategy before generation so failure does not force story compromise.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
