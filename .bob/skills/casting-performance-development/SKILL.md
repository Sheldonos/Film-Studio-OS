# Casting & Performance Development

## When to use
Develop casting breakdowns, audition materials and evidence-based evaluation plans while preserving human hiring, consent and accessibility authority.

## Procedure
1. Start from the locked character bible, screenplay version, performance objectives, schedule, geography, accessibility needs and authorized representation boundaries.
2. Create role breakdowns covering story function, playable objectives, relationships, age range only where narratively necessary, skills, language, movement, intimacy, stunt, singing, voice and schedule needs without discriminatory proxy criteria.
3. Design audition sides and self-tape or session instructions that minimize sensitive disclosure, protect script access, state accommodations and consent, and avoid unauthorized digital-replica capture.
4. Build a weighted evaluation matrix for role-specific evidence such as listening, transformation, chemistry, continuity, vocal or movement requirements; separate observable evidence from taste and confidence.
5. Plan recalls, chemistry reads, accessibility accommodations, safeguarding, intimacy/stunt consultation and conflict checks; flag availability, exclusivity and location assumptions for human teams.
6. Return a shortlist decision support package with rationale, conflicts, unanswered questions and consent/rights checkpoints; never rank protected traits or make the hiring decision.

## Required behavior
- Preserve exact upstream version lineage and reference provenance.
- Separate verified evidence, inference, assumptions and unknowns.
- Require independent review for consequential artifacts.
- Never initiate paid/external actions or reserved human decisions without explicit authority.
