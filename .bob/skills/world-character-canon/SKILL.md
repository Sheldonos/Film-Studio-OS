# World Character Canon

## When to use
Create persistent world, location, prop, wardrobe and character identity/state canon for reuse across shots and episodes.

## Procedure
1. Separate immutable identity/world rules from mutable scene state; never encode “wet jacket in scene 14” as permanent character identity.
2. Create canonical identity anchors, turnarounds/model-sheet requirements, expression/pose ranges, voice/casting constraints, wardrobe families and allowed variation.
3. Build WorldBible/LocationBible with geography, architecture/material language, technology/era rules, palette/motif, weather/time states and prop canon.
4. Assign stable IDs to characters, locations, costumes, props and motifs; every scene/shot references IDs plus state versions rather than prose-only memory.
5. Record negative constraints that prevent common identity/world drift without overconstraining legitimate performance variation.
6. Validate new art/reference assets against canonical traits before promotion; rejected variants remain lineage data but never silently become canon.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
