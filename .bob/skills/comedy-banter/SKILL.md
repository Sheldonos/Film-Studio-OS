# Comedy Banter

## When to use
Build character-driven wit, banter, joke mechanics and callbacks without interchangeable joke insertion.

## Procedure
1. Load tone boundaries, character comic perspectives, relationship history, scene objective and current stakes before generating any joke.
2. Identify comic engine per beat: incongruity, status collision, literalism, misdirection, escalation, rule-of-three, callback, reversal, embarrassment, denial or character-specific worldview.
3. Write setup with only information required for the turn; place the turn at the latest intelligible point and give the button to the character whose status/relationship consequence matters most.
4. For banter, vary volley length and tactics; let wins/losses accumulate rather than alternating symmetrical quips.
5. Protect tension beneath humor. If a joke releases pressure, decide whether the scene should rebuild it immediately or use relief as the turn.
6. Track callbacks as setup/payoff assets and avoid repeating premise after the audience has understood it.
7. Table-read at target pace; cut overwritten tags, explanatory laugh lines and jokes that break character voice, genre or emotional truth.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
