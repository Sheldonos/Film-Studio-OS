# Production Team Simulation

## When to use
Use when planning a film, series, animation or documentary; when running a writers' room or department review; or when the user asks which production roles must contribute.

## Procedure
1. Load the project type, production route, lifecycle stages, authoritative creative package, constraints and `policies/production_role_registry.json`; reject an unknown project type or route.
2. Run `film-studio team-plan` or the bounded MCP team-plan tool so every one of the 227 registry roles receives exactly one traceable disposition.
3. Separate required human authority from simulated advisory coverage. Never portray Bob as counsel, financier, accountant, licensed operator, safety specialist, consent authority, performer, employer or final approver.
4. Route each applicable advisory perspective to its accountable Bob department persona, preserve the role's source responsibility and record any combined coverage used for a generative production route.
5. Stop at unresolved human blockers, stale inputs, rights restrictions or stage ambiguity; provide the exact missing role/decision instead of inventing an approval.
6. Synthesize department contributions into conflicts, dependencies, risks and handoffs. Require independent review of the final coverage matrix before it controls a production workflow.

## Required behavior
- Preserve role provenance and report all 227 dispositions, including not-applicable roles.
- Treat simulated contributions as advisory analysis, never real employment or professional sign-off.
- Never initiate a paid/external action without explicit authorization.
