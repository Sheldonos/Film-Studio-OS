# Story Architecture

## When to use
Design or diagnose premise, causal structure, escalation, reveals, setups/payoffs, climax and runtime allocation.

## Procedure
1. Load premise, theme/countertheme, genre contract, audience promise, target runtime and locked adaptation/creative constraints.
2. Define the dramatic question and causal story engine in verbs: who pursues what under what recurring pressure, and what forces irreversible choices.
3. Build sequence-level state transitions rather than labels: incoming goal/power/information/emotion, complication, turn/reversal and outgoing state.
4. Trace the causal spine with “because/therefore” links. Flag “and then” adjacency unless it is an intentional pause, montage or tonal reset with a defined function.
5. Place setups/payoffs, reveal order, midpoint pressure shift, crisis choice and climax so each materially changes available options or stakes.
6. Budget runtime by sequence/episode function and test removability: if a unit can disappear without causal, emotional, thematic or setup/payoff loss, combine or cut it.
7. Run counterfactual structures and select based on audience effect, character agency and production cost—not template conformity.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
