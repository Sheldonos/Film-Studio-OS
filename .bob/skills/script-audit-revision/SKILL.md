# Script Audit Revision

## When to use
Run independent multi-pass screenplay diagnosis, ranked revision planning and regression verification without silent rewrites.

## Procedure
1. Freeze the draft/version and run independent passes separately: cold read, premise/theme, structure/causality, character/agency, scene function, dialogue/voice, continuity/logic, genre/tone, production feasibility and table-read timing.
2. Each finding must cite page/scene/beat/line evidence, severity, confidence, root cause, downstream consequence and whether it is diagnosis or optional rewrite direction.
3. Deduplicate notes by root cause; do not ask writers to fix five symptoms independently when one structural issue drives them.
4. Arbitrate conflicting notes against frozen creative invariants and decision ownership; preserve rejected alternatives and rationale.
5. Create a ranked revision plan with change budget, dependency/invalidation forecast and stop conditions.
6. Apply approved revisions locally whenever possible; do not opportunistically polish unrelated text.
7. Run regression audit after revision to prove the target metric improved without breaking prior strengths, setups/payoffs, continuity or runtime.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
