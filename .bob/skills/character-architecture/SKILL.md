# Character Architecture

## When to use
Create and audit character identity, wants/needs, arcs, relationships, state and voice anchors for production.

## Procedure
1. Load source canon, premise/theme, ensemble needs and all prior CharacterState/RelationshipState versions.
2. Define surface want, underlying need, fear/wound/lie/contradiction, competence, vulnerability, values/moral limits and pressure behavior as testable dramatic tendencies.
3. Give each character an agency map: decisions they can make, leverage they hold, information they possess and tactics they prefer under rising pressure.
4. Design relationship arcs independently from individual arcs; track status, trust, debt, intimacy, resentment, secret and leverage changes at scene boundaries.
5. Create a voice fingerprint using diction, syntax, cadence, directness/evasion, metaphor domain, humor strategy and taboo/avoidance—not catchphrases alone.
6. Plot irreversible choices and evidence for psychological change. Do not assert an arc because costume, mood or exposition says the person changed.
7. Stress-test ensemble overlap: if two characters make the same decisions, jokes and exposition in the same voice, differentiate function or consolidate deliberately.

## Required behavior
- Preserve approved creative intent and exact upstream version lineage.
- Separate verified evidence, inference and unknowns.
- Never let authoring stand in for independent final review.
- Never initiate a paid/external action without explicit authorization.
