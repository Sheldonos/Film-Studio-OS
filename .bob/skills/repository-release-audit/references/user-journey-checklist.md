# First-Time User Journey Checklist

Trace each applicable flow from a new user's first command through a durable result:

- Install and validate the Bob package.
- Create/inspect a project and ingest a source securely.
- Clear rights and consent or understand the exact blocker.
- Run book-to-film adaptation.
- Run script-to-feature, series, animation and documentary routes.
- Simulate script notes and all production-role contributions without false authority claims.
- Compile a shot and run a mock generation pilot.
- Discover Higgsfield schema, build a dry run, preflight cost, authorize, submit and monitor.
- Resume after human approval/review and recover from a failed job.
- Perform final QC, localization/accessibility, archive, deliverables and reproduction.

For each flow evaluate completion, truthfulness of success states, actionable errors, recovery, consistent terms/copy and user trust. Mark Complete, Incomplete or Broken with severity. Anything that falsely claims rights, payment, approval, staffing, generation or release is trust-breaking.
