# Research Basis and Boundaries

## User specification

The package implements the supplied requirements for atomic decomposition, independent author/reviewer paths, screenplay intelligence, continuity, provider-neutral generation, explicit quality gates, production memory, rejection learning and regression benchmarks.

## Current Higgsfield public product surface checked (2026-08-15)

Higgsfield publishes an official CLI/MCP and skills repository for image, video and audio generation. The current documented CLI uses `higgsfield generate create <job-set-type>`, `higgsfield model list/get`, `higgsfield generate cost/get/wait/list`, and workflow commands. Model parameters are dynamic, so the adapter queries the installed CLI's live schema instead of freezing a model catalog. These are optional execution adapters, not the architecture's source of film logic.

## Cully Hill Boys boundary

The film/build is published under HOL-RO-1.0, which permits study but restricts reuse of release materials. This package intentionally contains no copied production prompts, seeds, workflows, references, character assets, or parameter sets from that release.

Source:
- https://higgsfield.ai/licences/hol-ro-1.0
