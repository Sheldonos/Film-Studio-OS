# First-Time User Journey Audit — v0.4.0

### Open a fresh clone in IBM Bob
**Status:** ✅ Complete  
**Issue:** `AGENTS.md` tells the user which mode enables skills, where to verify project discovery, how to run a read-only readiness check, what installation changes, and how to recover. The current audit sandbox lacks pytest/jsonschema/MCP, and the check reports that honestly.  
**Severity:** None

### Upload a book or script and ask “what are we missing?”
**Status:** ✅ Complete  
**Issue:** Ingestion is followed by a deterministic diagnostic that groups blocking/nonblocking gaps, explains consequences and asks one prioritized question backlog. It never reports the completeness score as a greenlight.  
**Severity:** None

### Begin a master conversion route
**Status:** ✅ Complete  
**Issue:** Book-to-film and all four script routes now require the diagnostic immediately after ingestion and before rights, revision, series, animation or documentary development. Missing reviews/approvals pause visibly.  
**Severity:** None

### Plan casting, character references and appearance
**Status:** ✅ Complete  
**Issue:** Casting briefs/sides/evaluation, multi-view character identity, costume/hair/makeup and scene-state continuity form one independently reviewed workflow. Hiring, likeness consent and performer-facing decisions remain human.  
**Severity:** None

### Prepare a physical or hybrid production
**Status:** ✅ Complete  
**Issue:** Breakdown, design, location, risk, schedule/budget, art execution and operations are traceable workflow steps. Remote location observations and safety triage never masquerade as permits or specialist approval.  
**Severity:** None

### Control a shoot day and location sound
**Status:** ✅ Complete  
**Issue:** Day-control, qualified safety handoff, sound plan, continuity, capture QC and dailies form a controlled route. The workflow pauses at the human safety gate.  
**Severity:** None

### Build business, finance and release strategy
**Status:** ✅ Complete  
**Issue:** Chain-of-title/package checklists, finance scenarios, audience hypotheses and distribution delivery plans distinguish assumptions from evidence and require human release authority.  
**Severity:** None

### Use Higgsfield
**Status:** ⚠️ Incomplete for live production  
**Issue:** Installation/authentication is intentionally excluded from bootstrap. Discovery, prompt compilation, cost preflight and dry-run are covered; live account behavior still requires approved studio UAT.  
**Severity:** Medium

### Operate as a multi-user enterprise system
**Status:** ⚠️ Incomplete  
**Issue:** Role and approval checks exist, but the package does not provide SSO, tenant isolation, centralized secret storage or a hosted audit database.  
**Severity:** High for live enterprise deployment; not a blocker for the governed local beta

## Trust-breaking review

No core local flow claims that Bob installed a missing package, loaded a skill in the Bob UI, cleared rights, hired talent, approved safety, generated paid media or secured distribution when it did not. Remaining external dependencies are named at the decision point with an actionable next owner.
